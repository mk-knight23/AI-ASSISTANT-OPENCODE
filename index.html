Free Tier Setup

Zero Cost AI Coding in 5 Minutes

Get a powerful AI coding agent running for free using Nvidia Build's model catalog.

free-tier-setup.sh
# Step 1: Install Opencode
$ npm install -g opencode-ai
✓ Opencode installed

# Step 2: Register at build.nvidia.com (free)
# Get your API key from the dashboard

# Step 3: Configure for free Nvidia Build models
$ cat ~/.opencode/config.json
{
"provider": "nvidia",
"baseUrl": "https://integrate.api.nvidia.com/v1",
"apiKey": "nvapi-your-key-here",
"model": "nv-us/kimi-k2.5" // or minimax-m2.5
}

# Step 4: Start coding for free
$ opencode "add error handling to the login endpoint"
→ Using Kimi K2.5 via Nvidia Build (FREE)

Features

Open Source Power

LSP Integration

Automatically loads TypeScript, Python, Go, Rust, Java LSPs. LLM gets semantic type info, import graphs, and diagnostics.

Multi-Provider

Anthropic, OpenAI, Nvidia Build, OpenRouter, Moonshot, Minimax, AliCloudCoding — swap providers in seconds.

Terminal Native

Run anywhere a terminal runs — SSH sessions, CI/CD, Docker containers, remote servers. No GUI required.

Open Source

Fork, customize, self-host for maximum privacy. No vendor lock-in, no per-seat licensing, community-driven.

Hacker-Friendly

Cross-Platform
